The new command `wayloop validate --input <file>` checks briefs against their schema and reports every error in one pass: the pointer of the faulty value and the document it belongs to, the reason, the accepted values or the corrected key, and the file and line where the value is stored. A brief written against an unknown schema version is refused with the versions the engine knows. Checks of the other artifact types are listed as not done in the result until they are built. The command always prints a JSON result, also when its command line is wrong or its input file cannot be read.
