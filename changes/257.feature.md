`wayloop validate` now reads the project itself: with no argument it checks every brief, council report and plan item under `plan/` and every living specification under `specs/`, or only the files you name. Each error points to the file and the line of the faulty value. YAML files are read strictly: `no`, `on` and dates stay text, a key written twice is refused, and very large or self-expanding files are refused without being loaded. Files reached through a symbolic link that leaves the project are never read.
