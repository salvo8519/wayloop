`wayloop validate` now reads the project itself: with no argument it checks every brief, council report and plan item under `plan/` and every living specification under `specs/`, or only the files you name. Each error points to the file and the line of the faulty value. YAML files are read strictly: `no`, `on` and dates stay text, and a key written twice is refused. Reading is bounded: at most 10,000 files, 1 MiB per file, and a budget of counted bytes, an estimate of memory, per file and for the whole project; a file beyond a bound, or one whose aliases would expand it beyond its budget, is refused without being loaded. Files reached through a symbolic link that leaves the project, or that turns another file into an artifact, are never read.
