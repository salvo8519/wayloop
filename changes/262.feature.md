`wayloop validate` now refuses two artifacts that carry one identifier. Each of them gets the
error `identifier_duplicate` at `/id`, and the error names the other documents in the new
optional member `related` of the error report: their index in `documents`, the pointer and,
when the document was read from a file or the tracker, where it is stored. An artifact read
from a file whose name, or whose folder number for a living specification, gives another
identifier than its `id` passes with the warning `identifier_location`, whose `fix` is the
identifier.
