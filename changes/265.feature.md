`wayloop validate` now checks living specifications written in Markdown. Each
`specs/<NNNN>-<capability>/spec.md` is normalised into the document model of a living
specification (title, header rows, sections, requirements, acceptance criteria and their
verification words, open questions) and validated by the same schema as a specification sent in
normalised form, with the file and the line of every error in `source`. Sections outside the
template, a translated heading included, are kept as prose; a verification text with no known
word is refused with the reason `enum`. The check `markdown` moves from `diagnostics.not_done`
to `diagnostics.checks`.
