`wayloop validate` now checks the branch of each pull request and the header of each commit,
and the title of each pull request as a header. A branch must be `<type>/<issue>-<slug>` or
`sprint/S<NN>/<issue>-<slug>`, with a slug of at most five words; Dependabot, release and revert
branches are exempt. A header must be `<type>(<scope>)[!]: <subject>`, with a type and a scope
of the policy, a subject that starts with a lower-case letter and has no final full stop, and at
most 72 characters. A commit that marks a breaking change with `!` needs a `BREAKING CHANGE:`
paragraph in its body. Errors carry the accepted types or scopes in `expected`, and the
corrected branch or header in `fix` when one can be derived. The check of the issue links of a
pull request is still listed as not done.
