The published schemas of `wayloop validate` and of the result envelope now state that every
pointer is an RFC 6901 JSON pointer (format `json-pointer`), and the schema of `lines` states
that its keys are pointers and its values line numbers from 1. A client can check these rules
with any JSON Schema validator that checks formats (format assertion enabled), instead of
learning them from the documentation. A key of `lines` that is not a pointer is now reported
with a message about the name of the member.
