`wayloop validate` run outside the root of a project, where no folder of stored artifacts
exists, now says so with the warning `artifact_location_missing` instead of succeeding silently
on an empty set. The input gains the optional member `locations`, the folders found by
discovery; the check is listed as `artifact_locations` in `diagnostics.checks` when it is given,
and in `diagnostics.not_done` with the reason `input_absent` when it is not, as for every input
sent with `--input` or files named on the command line.
