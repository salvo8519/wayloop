`wayloop validate` now checks the ADR citations of living specifications on a project that
keeps its ADRs in `docs/en/project/adr/`: it reads the ADR numbers from the file names
(`<NNNN>-<slug>.md`), and a citation such as `ADR 0042` with no such ADR gives the warning
`adr_citation_missing`. A project without that folder is not checked, as before.
