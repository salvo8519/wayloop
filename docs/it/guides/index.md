# Guide

Questa sezione raccoglie le guide ai compiti svolti con Wayloop, da un agente di
programmazione o dalla riga di comando. Nessuna guida è pubblicata, perché nessun comando del
loop è rilasciato; il lavoro in quella direzione è nella [roadmap](https://salvo8519.github.io/wayloop/project/roadmap/).
